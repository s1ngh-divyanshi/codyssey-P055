# Codyssey — AI-Powered Coding & Analytics Platform

An interactive learning platform featuring Monaco Editor, automated code evaluation via Judge0 API, real-time Socratic hints powered by Google Gemini, and student analytics dashboard.

---

## Project Structure
- `client/`: React + Vite + Tailwind CSS frontend
- `server/`: Node.js + Express + MongoDB backend
